# Semantic Shorthand

High-fidelity, low-token inheritance logs that survive across AI sessions, models, and agents. Create durable notes, decision logs, and inheritance packages without summarization loss.

Choose the file that matches your need. Each is fully usable on its own for its stated purpose.

## Install
1. Pick a file below.
2. Copy the entire file.
3. Paste into your AI as a system prompt, custom instructions, project knowledge, or skill file.

## Files (recommended order)
- [`README.md`](README.md) — this file
- [`01.01_Semantic_Shorthand-Skill_Package.md`](01.01_Semantic_Shorthand-Skill_Package.md) — Full package. Complete language, logging, curation, inheritance, and Coding Mode.
- [`Semantic_Shorthand_lite.md`](Semantic_Shorthand_lite.md) — Fully capable lite version. Equivalent in ability to the full package at lower token cost.
- [`Semantic_Shorthand_Language_and_Grammar.md`](Semantic_Shorthand_Language_and_Grammar.md) — Language and notation only. Read and write expressions, Special Sets, Math Mode, currying, and Absolute/Invariant.
- [`Semantic_Shorthand_Logging_Curation_Inheritance.md`](Semantic_Shorthand_Logging_Curation_Inheritance.md) — Logging, curation, and inheritance practice only. Start, structure, curate, and hand off logs (assumes language is known).
- [`Semantic_Shorthand_Log_Examples.md`](Semantic_Shorthand_Log_Examples.md) — Concrete example logs showing the notation in use.
