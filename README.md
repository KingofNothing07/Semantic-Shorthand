# Semantic Shorthand

**High-fidelity, low-token inheritance logs that survive across AI sessions, models, and agents.**

Create durable notes, decision logs, and inheritance packages without the usual summarization loss. Sacred content — decisions, reasoning, relationships, conditionals, dependencies, and outcomes — stays reconstructible so a later reader (human or AI) can continue with minimal rediscovery.

Only approved material enters the main log. Compression re-encodes; it never discards essential detail. The result is a living context engine that stays accurate and token-efficient across long-running work.

## Why try it
- Survive session hand-offs and model changes without losing critical context.
- Keep multi-agent or multi-session projects coherent.
- Ideal for design/architecture logs, software design (including Coding Mode), academic work, creative projects, and any work that must remain accurately reconstructible.
- Fully capable lite version available for lower token cost with equivalent power.

## Install (30 seconds)
1. Choose the file that matches your need (see below).
2. Copy the **entire** file.
3. Paste it into your AI as a system prompt, custom instructions, project knowledge, or skill upload.

Each file is fully usable on its own for its stated purpose. Notation is protected in fences — plain text or fenced Markdown is safest. Disable autocorrect in rich-text tools.
